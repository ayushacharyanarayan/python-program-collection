# Python Programs Collection

A collection of beginner-friendly Python programs.

## Programs
- **factorial.py** – factorial using a loop and recursion
- **fibonacci.py** – Fibonacci series and recursive nth term
- **structure_to_dict.py** – converting lists and objects into dictionaries

## How to run
```
python factorial.py
python fibonacci.py
python structure_to_dict.py
```

## Sample output
```
Enter a number: 5
Factorial of 5 (loop): 120
Factorial of 5 (recursion): 120
```
